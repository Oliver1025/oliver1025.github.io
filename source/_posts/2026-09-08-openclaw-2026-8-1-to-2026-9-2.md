# OpenClaw 更新解读 (2026.8.1 → 2026.9.2)

本次版本跨度从 2026.8.1 到 2026.9.2，中间经过 2026.9.1（基线版本，1223 个 PR 已随基线发布）与 2026.9.2 两个阶段。2026.9.2 本身合并了 **1247 个 PR**，Highlights 6 项，Changes 与 Fixes 数十项。本次重点：**聊天与仪表板响应提速**、**升级与恢复可靠性**、**GPT-6 Astra 支持**、**重启后回复恢复**、**备份完整性**、**免重启改配置**、**Swarm 默认开启**、**实验性插件 UI / Apple Watch Talk**。

> 本次更新无微信插件相关变化（插件仍为 not_installed 状态）。

---

## 核心亮点（Highlights）

### 更快、更流畅的聊天体验

长对话记录与磁盘使用统计的处理不再阻塞聊天、仪表板和会话交互：仪表板直接查询、冷启动加载减少、持久化历史读取移出 Gateway 事件循环，整体响应更迅速。

### 可靠的升级与恢复

自动更新过程保留已激活的设置、启用的技能和默认 agent 归属；Git 更新后可恢复 Gateway 重启；升级结果附带可操作的恢复指引。

### GPT-6 Astra 支持

选择 `openai/gpt-6-astra`（需 OpenAI API-key 或符合条件的 ChatGPT/Codex 账户），支持文本与图片输入、Responses 工具调用及推理控制。

### 回复在重启后存活

Gateway 重启后可恢复活跃、排队中和委托中的回复，且一条完成的回复不会丢弃另一条的恢复标记；续写指令在压缩与重试中保持不变。

### 备份保护数据完整性

Git 备份保留包含内嵌 NUL 字符的完整文本，支持 Nix 管理的配置与凭证软链，损坏的归档头会被拒绝而非接受不完整备份。

### 免重启修改设置

更多 agent、模型、工具、渠道、浏览器、节点、访问和终端设置可在运行中生效；仍需重启的设置在配置参考中明确标注。

## 主要变更（Changes）

### Swarm 默认开启

并发 sub-agent 编排（结构化结果 + 实时进度）默认启用，同时保留显式退出、工具限制和 Code Mode 单独启用的机制。

### 实验性插件 UI

设置 → 实验室（Labs）→ 自定义插件 UI：插件可向控制界面贡献页面、面板、会话操作，或自定义 composer 与工作区。

### 实验性 Apple Watch Talk

独立运行于 Apple Watch 的 Talk 应用，由 Gateway 持有工具与转录；独立实时音频需要 UDP 连通性。

### GPT-6 Astra 异步工具与转向

OpenAI Platform API-key 路由（内置运行时 + 官方 Responses 端点）支持直接函数工具异步执行、基于缓存 WebSocket 的实时转向，以及在调整推理力度时保留请求前缀。

### 个人连接账户

设置 → 个人资料 → 连接账户：可添加 provider 账户，为新聊天或某个现有聊天选择账户；默认切换时保留既有会话选择。

### 仪表板适配任务

浏览保存的仪表板画廊，切换聊天/仪表板视图，面板可放置在左、右或下方，隐藏与重新打开面板时保留已加载的组件输入。

### 跨 agent 会话访问

会话工具默认对所有会话可见，普通 agent 间互访默认开启；可用 `tools.sessions.visibility` 收窄为 `agent` 或 `self`。

### 设备一览

设备页展示设备类型、资源占用、能力标签和桌面端可用性；iOS 原生 CPU/内存与 Android 内存/磁盘上报。

### Discord 会议纪要

可开启基于占用检测的只听会议捕获，自动生成纪要并新增控制界面"会议"页。

### Slack 富回复

指导 agent 在主动 Slack 回复中使用受支持的 Block Kit 布局。

### 把队友拉进对话

composer 中可提及授权人员，收到临时收件箱条目，可选浏览器通知。

### 实时 Talk

为轻量音频客户端提供原生实时会话，保留所选模型与账户、转录、语音控制和范围化 agent 会诊。

### 云 worker 检出

替换型云 worker 快进到已推送的会话分支，保留本地修改、有意删除和分叉分支。

### Owner 档案

单用户 Gateway 连接获得持久 Owner 档案，承载身份与个人偏好，不额外授予权限。

### macOS 浏览器登录

通过个人 Cloudflare Access 浏览器登录连接已保存的 Gateway；从 Gateway 网站打开 Mac 应用；应用重启后恢复所选 Gateway。

### 插件品牌化

插件图标打包至 `assets/icon.png`，无需网络请求加载；图标缺失或无效不再阻止插件加载。

## 重要修复（Fixes 摘选）

- **问答确认**：恢复丢失的答案确认，不再通过普通 steering 重复发送同一输入；不确定的结果可见上报。
- **HTTP 代理安全**：更新 HTTP 依赖，请求绕过已配置代理时保持目标 DNS 检查。
- **长对话**：准备长转录期间 Gateway 保持响应，取消操作在历史准备全程有效。
- **压缩记账**：历史修复中移除的孤儿、重复和错位工具结果计入丢消息摘要与 token 总量。
- **自动化回复**：自动化与心跳完成保持挂接到原会话与主题，同时保留隔离的执行会话。
- **Cron 任务**：自动化自移除时保留最终回复；编辑/克隆时保留失败告警策略。
- **记忆召回**：轮换召回保持；显示数据库、WAL 和嵌入缓存用量及安全离线磁盘恢复指引。
- **Slack 送达**：丢失流式确认后避免重复回复；显式限流拒绝在送达与上传中重试。
- **WhatsApp 终端结果**：送达 turn 失败、超时或拒绝的原因，不再让对话静默。
- **Telegram 代理媒体**：通过显式配置的 SOCKS 代理与 HTTPS 代理请求恢复媒体传输。
- **技能工坊备份**：拒绝不完整目录快照，恢复前校验保留的原始文件。
- **逐轮设置**：内联思考、详略程度和授权 tracing 严格限定在当前轮内，不受排队、模型切换和 fallback 影响。
- **Code Mode 恢复**：失败单元格交还普通 agent 循环，agent 可检查部分效果并继续任务。
