# OpenClaw 更新解读 (2026.7.1 → 2026.8.1)

本次是一次**超大跨度**版本，从 7-1 到 8-1 跨过约 50 天，**贡献者达 109 位**，合并了大量 PR。Highlights 8 项，Changes 与 Fixes 数百项。本次重点：**跨设备/云端会话迁移**、**持久进度卡**、**结构化交互（问答/分支/队列）**、**凭证管理革命**、**插件生态重塑**、**多渠道协同全面升级**、**模型阵容扩展**、**本地化推理**。

> 微信插件（openclaw-weixin）已由聪哥手动卸载，2.4.6 → not_installed。本篇仅覆盖 OpenClaw Core 自身更新。

## 核心亮点（Highlights）

### 查找过往对话

按精确词语或短语搜索可见会话文本，并从匹配结果重新打开上下文消息。

### 跨 Gateway 的会话

会话可在**配对设备**或**云 worker** 上运行，工作区随之迁移，复用预热机器与项目种子。

### 持久进度卡

跨重新加载保留会话进度卡，跟踪 subagent 活动与累积编辑。

### 结构化问题答复

通过 Web / 原生卡片、消息按钮或纯文本回复结构化 agent 问题，支持 free-text 替代和明确的 Skip 路径。

### 交互式结果和仪表板

聊天中使用小部件，钉到会话仪表板，授予特定操作或网络来源，可导出渲染视图为图片。

### 私有凭证请求

agent 通过 masked prompt 请求凭证，**值不进聊天/模型上下文**；可选代理限制 protected-secret 仅替换到批准的目标。

### 一次性批准循环工作

为精确操作授予自动化权限，可稍后检查/撤销，操作变更时要求新批准。

### 丰富的音频和视频

媒体在上传、生成回复、播放、刷新间保持挂载，原生播放控制，Apple/Android 客户端支持视频上传。

## 主要变更（Changes）

### 🚨 破坏性变更

**OpenProse 迁移（破坏性）**：移除捆绑的 OpenProse 插件和 `/prose` 命令，需运行 `openclaw doctor --fix` 清理旧配置。现有 `.prose` 源文件保留。

**OpenAI 路由迁移（破坏性）**：shipped 的 `codex/*` 和 `openai-codex/*` 模型引用/provider 配置/存储会话/自动化路由全部迁移到 `openai/*`，保留 Codex 运行时意图，冲突标记为操作员待修复。

**SDK 弃用预告（2026-09-01）**：外部插件需在 SDK 移除门槛前完成迁移：
- `plugin-sdk-config-runtime-subpath` → `api.pluginConfig` 和 focused `openclaw/plugin-sdk/config-*` imports
- `plugin-sdk-channel-reply-pipeline-subpath` / `plugin-sdk-channel-lifecycle-subpath` → `openclaw/plugin-sdk/channel-outbound`
- `plugin-sdk-channel-message-subpath` → `channel-outbound` + `channel-inbound`
- `plugin-sdk-infra-runtime-subpath` → focused `delivery-queue-runtime`、`diagnostic-runtime` 等

### 🤖 模型与 Provider 扩展

**新官方 Provider 包**：BytePlus、ComfyUI、Mistral、NovitaAI、OpenCode、Synthetic、Volcengine、Vydra、Xiaomi、Cohere、Meta、DuckDuckGo 搜索、Voyage embeddings、iMessage messaging。

**新模型**：
- Qwen 3.8 Max / Flash
- DeepSeek V4 Flash Vision（Experimental）
- NVIDIA Nemotron 3.5 Lightning
- GLM-5.3 / Flash

**OpenAI 长上下文选择加入**：明确启用扩展的活动输入上下文，与模型原生容量区分。

**实时模型发现**：从受支持的 provider 发现可用模型，不仅依赖内置目录快照。

**实用模型默认值**：未配置 utility 模型时使用 provider 声明的小模型生成短标题与进度。

**OpenAI 模型选择**：新 API-key 和 OAuth 设置使用 `openai/gpt-5.6-sol`。

### 🔐 凭证与权限管理

**共享凭证库（SQLite）**：通过 CLI 和 Settings 管理团队范围的 secret 和环境条目，secret 值仅写；区分可读 env 值与 secret。

**可选 1Password broker**：通过 service-account 鉴权解析精选 SecretRefs 或读取 1Password 字段，每次 secret 单独批准。

**私有凭证请求**：agent 通过 masked prompt 请求凭证，值不进聊天/上下文；opt-in 代理限制替换到批准目标。

**明确模型 allowlists**：别名与每模型设置与 `modelPolicy.allow` 区分；doctor 迁移遗留限制而不静默打开访问。

**会话权限模式**：选择明确会话权限模式，新创建 worktree 继承配置策略。

**插件安装来源警告**：CLI/chat 安装任意可执行插件源需 `--force`；trusted ClawHub/bundled/official-catalog/tracked-update 源跳过。

**更清晰的插件信任**：安装/启用前审查能力、源、版本、精确制品。

## 主要修复（Fixes 摘要）

- **数据安全**：避免 WAL split-brain 清理破坏数据库；virtiofs 和 9p 挂载使用回滚日志。
- **配置完整性**：长数字标识符和明确字段类型保存时不四舍五入；已声明的兼容性设置被接受。
- **会话重置边界**：保留离开的会话摘要在重置前。
- **插件更新与同意**：保留明确能力同意，包重启时完成插件收敛。
- **GitHub 集成 / Git 操作**：剥离 refs 前 hosted-repository 解析，拒绝穿越段。
- **Unicode 安全**：UTF-16 代理对在压缩预览/标签/会话键/身份值中保留。
- **凭证 egress**：Gradium TTS 拒绝非 HTTPS / 异主机 / 主机名相似 base URL。
- **自动化恢复**：中断的 one-shot job 重启后恢复；webchat-only Gateway 支持 current-session 自动化。
- **心跳传递**：在目标会话中暴露已传递的 alert，关闭重启恢复 gap。
- **聊天重复**：防止重复 Enter 键、跨客户端 steering 和终端结算重复可见消息。
- **网关 exec deny fallback**：`ask=off` 和 `askFallback=deny` 下 shell 扩展阻止可强制执行白名单执行计划时 fail closed。
- **Provider 限速**：共享限速窗口解析在重试路径间。
- **大量小修复**：跨 100+ 子系统稳定性、性能、隐私、安全、模型加载、跨平台兼容。
