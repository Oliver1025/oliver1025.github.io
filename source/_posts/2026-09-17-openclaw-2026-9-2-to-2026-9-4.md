# OpenClaw 更新解读 (2026.9.2 → 2026.9.4)

本次版本跨度从 2026.9.2 到 2026.9.4，中间经过 2026.9.3 与 2026.9.4 两个发布阶段。2026.9.4 合并 **1,174 个 PR**，Highlights 8 项；2026.9.3 规模约 1,844 个 PR。本次重点：**更新失败自动回滚**、**插件统一管理**、**云端会话快照**、**终端问答交互**、**GPT Image 2.5**、**对话历史可靠性**、**浏览器自动化实时观看**、**可撤销聊天分享链接**。

> 本次更新无微信插件相关变化（插件仍为 not_installed 状态）。

---

## 核心亮点（2026.9.4）

### 更新失败自动回滚

升级失败时若校验证明可安全回滚，OpenClaw 会保留旧版本包，并用旧配置和服务恢复运行。涉及数据库 schema 变更的升级仍要求事先验证过的备份，不会盲目回滚；已恢复的更新仍标记为失败更新并记录回滚结果。

### 插件一站式管理

Control UI 新增统一的插件工作区：浏览内置与 ClawHub 插件、直接安装、集中管理设置与访问权限。支持按分类浏览已装插件、短链接插件页面（如 `/reports`），并通过统一搜索发现已安装与 ClawHub 技能。

### 云端会话准备

可从已准备的本地项目或公开 GitHub 仓库启动符合条件的 Linux 云端会话，并在对话开始前构建可复用快照（snapshot），减少重复环境搭建。默认每个项目/配置文件保留一个预备 worker，全网关上限 4 个，可配置为 0 关闭。

### 终端问答交互

TUI 会话支持键盘方向键/数字键选择、自由文本回答和多问题提示；本地模式下问答仅在当前 TUI 进程内有效，可用 `/question` 重新打开待回答提示。

### GPT Image 2.5

图像生成与编辑新增 Flare 和 Sunburst 两种变体，通过 OpenAI 或 fal 即可选用，无需更改现有默认模型。

### 更可靠的对话历史

流式回复中断后可恢复最终答复、重载后保留超时提示、实时聊天切换到历史记录时不再出现重复的最终回答。相关修复还覆盖段落与代码块边界保留、Responses 截断回复标记为不完整等。

### 语音完成委派工作

Talk 模式可返回子代理（subagent）执行结果，即使经过多轮委派也能送达最终答案。

### 外部托管配置

新增 `OPENCLAW_CONFIG_READONLY=1`：适合由部署系统托管配置的场景，OpenClaw 不再改写配置文件，同时保留只读诊断和常规运行状态。该模式覆盖配置写入、Doctor 修复、插件变更与更新流程。

## 2026.9.3 阶段要点

2026.9.3 作为中间版本同样带来多项改进：更新恢复更干净、会话重连更快、浏览器自动化可实时观看、聊天分享链接可撤销、已保存的会议记录可搜索、云端工作支持仓库化运行。此外还有 Skill Workshop 技能跨工作区持久化、Mac 原生浏览器标签页、模型账户独立控制与排序等。

## 升级提示

2026.9.3 起对 Node 运行时有要求：Node 24.x 需 24.16.0 或更新，或使用 Node 26.1.0+（推荐 26）。升级 OpenClaw 前建议先确认 Node 版本，避免升级后无法启动。
