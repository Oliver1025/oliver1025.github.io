# 烟台4天3夜旅行攻略｜6月出行指南

夏天去烟台，看海、赶海、吃海鲜，这是最正确的选择。

---

## 行程一览

| 日期 | 白天 | 傍晚/晚上 |
|------|------|----------|
| Day0（周四） | 到达烟台·午饭·酒店 | 所城里·开花石（日落）·金沙滩·晚饭 |
| Day1（周五） | 烟台山·朝阳街·小红鲸海鲜午饭 | 17路双层巴士·渔人码头·滨海中路拍照·夜市 |
| Day2（周六） | 养马岛环岛·烧烤午饭 | 粉色贝壳沙滩·黄海明珠·烟大海水浴场·烟大夜市 |
| Day3（周日） | 文化路农贸市场·博物馆（可选）| 午饭·火车站返程 |

---

## Day0｜6月18日（周四）

**午饭 → 酒店放东西 → 孤独的鲸 → 金沙滩 → 所城里 → 开花石（日落+夜景）→ 晚饭 → 回酒店**

| 时间 | 安排 | 交通 |
|------|------|------|
| 12:00 | 午饭 | — |
| 13:00 | 打车去酒店，办入住放行李 | 🚕 |
| 13:30 | 打车去金沙滩海滨公园 | 🚕 约30元 |
| 13:30-15:30 | 孤独的鲸打卡拍照（开发区海滨公园西侧，铸铜雕塑《深呼吸》），沿金沙滩海边散步 | — |
| 15:30 | 打车去所城里 | 🚕 约20元 |
| 16:00-18:00 | 所城里逛老街拍照（明清卫所城池，"大字"打卡墙） | — |
| 18:00 | 打车到开花石山脚（旺角小渔村环山路店） | 🚕 约15元 |
| 18:00-18:30 | 爬山登顶（约20分钟） | — |
| 18:30-19:30 | 开花石等日落+夜景（世贸大楼约19:00亮灯），山上风大带外套 | — |
| 19:30 | 打车下山 | 🚕 |
| 20:00 | 晚饭 | — |
| 20:30 | 打车回酒店 | 🚕 |

## Day1｜6月19日（周五）

**早饭 → 烟台山 → 朝阳街 → 小红鲸海鲜午饭 → 17路双层巴士 → 渔人码头 → 滨海中路拍照 → 海水浴场 → 晚饭 → 夜市 → 回酒店**

| 08:30 | 打车到烟台山 | 🚕 约15元 |

| 12:00 | 午饭：小红鲸海鲜 | — |

| 13:00-14:30 | 17路双层巴士（往莱山方向，二楼左侧靠窗）<br>沿途：芝罘湾广场→第一海水浴场→月亮湾→栈桥→第二海水浴场→渔人码头 | 🚌 约2.5元 |

## 赶海时间参考

烟台6月潮汐规律：
- **傍晚赶海**：约18:00潮最低，Day1下午在海水浴场顺路赶海
- **注意**：粉色贝壳沙滩必须退潮时去，风大看不到
