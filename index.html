OpenClaw 更新解读 (2026.5.12 → 2026.5.28)

本次版本涵盖 OpenClaw Core 和 微信插件（openclaw-weixin） 两大更新，跨度约两周，带来多项稳定性与功能增强。

OpenClaw Core 更新要点

核心引擎优化

本次更新重点改善了 Agents 和 CLI 在异常场景下的恢复能力，包括：

  • 中断恢复：工具调用被打断、Session 绑定失效、媒体投递重试等场景现在能更干净地恢复（#88129, #88136, #88141, #88162, #88182）
  • 通道稳定性：Telegram、WhatsApp、iMessage、Slack、Discord、Microsoft Teams、Google Chat 等平台的消息通道更加稳定（#88096, #88105, #88183, #88231）
  • 定时器收紧：Provider 和插件请求的各类超时、OAuth 生命周期、媒体下载等路径均加了上限，防止请求挂起

Skill Workshop（技能工坊）

新增技能工坊功能，提供完整的 Control UI 流程：

  • 提案列表、今日操作视图
  • 可搜索的文件预览
  • 多语言本地化字符串
  • 支持文件上传与版本管理
  • 提案可原地修订，带版本和日期的 frontmatter

MiniMax M3 模型支持

正式支持 MiniMax M3 模型，相关提供商元数据已更新（#88860）。

SQLite 状态化

  • iMessage：消息监控状态、inbound 队列迁移到 SQLite 管理，重启后不再重复扫描文件系统（#88794, #88797）
  • 插件安装索引：同样持久化到 SQLite，提升插件查找效率（#88794）

控制面板（Control UI）改进

  • 新增「Dreaming」标签页，可选 Agent 并查看其状态/日记（#78748）
  • 聊天输入框优化：本地草稿保持、首次输出延迟监控、更冷静的控件渲染（#88772, #88998）

其他重要变化

分类 变化
Providers 新增 MiniMax M3；Google/Vertex 目录修复；OpenRouter SQLite 模型缓存；Copilot Claude 1M 支持
Workboard 新增多 Agent 编排与任务跟踪工具（#87469）
Plugins Tokenjuice 和 GitHub Copilot 插件正式独立发布
iOS 支持 iPad 原生布局；增强的实时 Talk 回放和 WebSocket ping
Doctor 新增磁盘空间健康检查
Memory 语义搜索写入序列化优化，QMD 更新/嵌入并发更安全

Bug 修复精选

  • 流式工具调用参数解析现在能正确处理 null 和数组等非对象 JSON
  • CLI 添加 Agent 时不再依赖 Provider 目录可用性（#76284, #88314）
  • 插件加载失败提供更清晰的修复指引
  • Cron 任务在模型限流后会重试而非直接跳过下一个时间槽
  • Chat UI 启动时聊天发送保留，不被历史加载阻塞
  • 安全配置拒绝不安全的 OAuth 令牌生命周期和时间戳

微信插件更新（2.4.3 → 2.4.4）

修复内容

  • iLink-App-Id / iLink-App-ClientVersion 请求头为空或为 0：生产环境下 readPackageJson 路径解析错误导致这两个 header 未能正确设置，新版通过向上遍历搜索插件自身的 package.json 解决
  • openclaw channels login 已连接时报错非零：自动化安装脚本会误报「首次连接未完成」，现改为检测 binded_redirect 状态并正常退出
  • 同步更新了 TypeScript 编译布局测试，覆盖 dev 目录、构建目录、嵌套 node_modules 等多种场景

本次更新概要

本次版本以修复为主，共收录了超过 100 项修复和优化，涵盖安全、渠道、插件系统、Gateway、会话管理等多个模块。

重要安全更新

  • Windows 沙箱加固：在沙箱Blocked Home Roots 中新增 Windows USERPROFILE，防止 .codex、.openclaw、.ssh 等敏感目录被不当访问。
  • 凭证推断防护：停止从宽泛的正则表达式推断提供商环境变量标记，仅通过结构化 secrets.providers[id] / secrets.defaults 解析 API Key，避免无关环境变量意外成为凭证。
  • 设备配对审批：新增设置码设备配对的审批要求、浏览器设备配对明确审批要求、Control UI 配对前代理作用域访问审批要求。
  • 可信代理源验证加固：强化可信代理源验证逻辑。
  • 会话传输敏感数据脱敏：在集中式 JSONL 追加路径中对敏感消息内容进行脱敏，CLI、Gateway 传输注入、轨迹镜像和保护的工具结果使用相同的脱敏行为。

渠道与消息

  • WeChat 插件更新至 2.4.2：
    • 修复 Node 24 / undici 兼容性问题（移除手动设置的 Content-Length 头）。
    • 修复 OpenClaw ≥ 2026.5.x 的 Weixin 运行时初始化超时重启循环（移除模块级 pluginRuntime 全局变量，改为按调用注入的 ctx.channelRuntime）。
  • Telegram 多项修复：
    • 保持 Bot API 轮询在主事件循环stall时活跃（移至独立 Worker + 本地持久化 spool）。
    • 保留懒加载 Cron 通知传递中的渲染 HTML 格式，Markdown 链接保持可点击。
    • 跳过 requireMention 激活时未提及的群组媒体，避免无效媒体下载回复。
    • 轮询停滞时从 getUpdates 活跃性检测，防止出站 API 调用掩盖死去的入站轮询。
    • 删除仅工具进度的草稿气泡，避免流式回复中残留孤立进度消息。
  • iMessage 修复：停止为纯媒体原生图片发送显示可见的 <media:image> 占位符。
  • LINE 入站媒体大小限制：避免完整缓冲超大附件。

Gateway 与会话

  • 会话历史优化：使用共享流式辅助工具替代全文件 readFile 扫描，200 MiB 合成会话峰值 RSS 从 +252 MiB 降至 +27 MiB。

  • 节点配对隐藏：待审批的节点配对命令、能力集和权限在审批前保持隐藏。
